# Machine Learning Journey

A collection of my machine learning experiments and implementations while building my foundation in classical machine learning and deep learning.

This repository documents my progression through different ML concepts, from traditional machine learning algorithms to neural network-based approaches.

## Projects

## Classical Machine Learning

### Sonar Rock vs Mine Classification
- Binary classification using sonar signal features.
- Explored supervised learning techniques for predicting whether an object is a rock or a mine.

### SMS Spam Classification
- Text classification project for detecting spam and ham messages.
- Applied NLP preprocessing and machine learning techniques for binary classification.

### IMDB Sentiment Analysis
- Sentiment classification of movie reviews using natural language processing.
- Applied:
  - Text cleaning and normalization
  - Spell correction using SymSpell
  - Stopword removal
  - Lemmatization using spaCy
  - TF-IDF feature extraction

Models implemented:
- Support Vector Machine (SVM)
- Multinomial Naive Bayes
- Logistic Regression

## Installation

Clone the repository:

```bash
git clone https://github.com/HarishChaisir/machine-learning-journey
cd machine-learning-journey
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

For the NLP projects, download the spaCy English language model:

```bash
python -m spacy download en_core_web_sm
```
